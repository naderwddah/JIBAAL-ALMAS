# جبال الألماس للرخام والحجر | Jibaal Almas Marble & Stone

موقع إلكتروني فاخر لشركة جبال الألماس للرخام والحجر الطبيعي، مصمم بأحدث التقنيات وأرقى التصاميم العربية الفاخرة.

## المحتويات

- `index.html` — الملف الرئيسي للموقع (HTML5 + Tailwind + GSAP + AOS)
- `css/` — ملفات التنسيق
  - `font-awesome/` — أيقونات Font Awesome 6.5.1
  - `aos.css` — تنسيق تأثيرات الأنيميشن عند التمرير
  - `webfonts/` — خطوط Font Awesome محلية
- `fonts/` — الخطوط العربية الفخمة
  - `google-fonts.css` — خطوط جوجل
  - `luxury-arabic.css` — خطوط عربية فاخرة (Amiri, Aref Ruqaa, Reem Kufi, El Messiri, Markazi Text, Tajawal, Lateef, Scheherazade New, Marhey, Lalezar, Rakkas, Galada)
  - `luxury/` — ملفات الخطوط (.ttf)
- `js/` — ملفات الجافاسكريبت
  - `gsap.min.js` — مكتبة GSAP للأنيميشن
  - `ScrollTrigger.min.js` — إضافة ScrollTrigger لـ GSAP
  - `main.js` — الكود الرئيسي للموقع
- `images/` — صور الموقع (رخام، حجر، مشاريع، خامات)
  - `marble/` — صور أنواع الرخام
  - `granite/` — صور أنواع الجرانيت
  - `stone-yard/` — صور ساحة الحجر
  - `projects/` — صور المشاريع المنجزة
  - `sinks/` — صور المغاسل الرخامية
  - `raw/` — صور الخامات
  - `decor/` — صور الزخارف
- `videos/` — ملفات الفيديو
  - `luxury-hero.mp4` — فيديو الهيرو الفاخر (30 ثانية, 1920x1080)
  - `VID-20260720-WA006*.mp4` — فيديوهات الشركة الأصلية
- `webfonts/` — خطوط Font Awesome الإضافية

## كيفية الاستخدام

### 1. الاستخدام المحلي
```bash
# استخرج الملفات
unzip jibaal-almas-source.zip
cd jibaal-almas

# افتح index.html في المتصفح
# أو شغّل خادم محلي:
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

### 2. الرفع على GitHub
```bash
# أنشئ مستودعاً جديداً على GitHub
# ثم:
git init
git add .
git commit -m "Initial commit: Jibaal Almas Marble & Stone website"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```

### 3. النشر على GitHub Pages
```bash
# بعد رفع الكود على GitHub:
# 1. اذهب لإعدادات المستودع (Settings)
# 2. اختر Pages من القائمة الجانبية
# 3. اختر Branch: main / root
# 4. احفظ — سيكون الموقع متاحاً على:

```
